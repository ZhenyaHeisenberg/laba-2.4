<h1>laba-2.4</h1>

<h2>Асинхронный исполнитель задач</h2>
<h2>Описание проекта</h2>

<p>Реализация асинхронного исполнителя задач из очереди с вызовом нужного исполнителя</p>
<ul>
    <li>- автоматическое определение нужного исполнителя по типу</li>
    <li>- запуск асинхронного исполнения задач из очереди</li>
</ul>

<h2>Executor</h2>

Исполнитель задач

<h3>Принцип работы</h2>
<ul>
    <li>- Инициализация - создается очередь задач и словарь обработчиков</li>
    <li>- Определение обработчика - по полю ```task.type``` выбирается подходящий обработчик`</li>
    <li>- Валидация - если обработчик не найден, выбрасывается ValueError</li>
    <li>- Асинхронный запуск - задачи выполняются асинхронно с ограничением по количеству с помощью Semaphore</li>
</ul>

<h2>Handlers</h2>

Обработчики

<h3>Принцип работы</h2>
<ul>
    <li>- вызывается исполнителем</li>
    <li>- принимает задачу со знакомым типом, знает, как ее обрабатывать</li>
    <li>- выполняет задачу, сохраняет логи</li>
</ul>

<h2>Масштабируемость</h2>

<p>Добавление нового обработчика:</p>

<ul>
    <li>- Создать файл c обработчиком в ```src/models/handlers/```</li>
    <li>- импортировать обработчик в ```executor.py```</li>
    <li>- Добавить в словарь _handlers в __init__ и сопоставить его типу задачи, который он будет обрабатывать</li>
</ul>

<h3>Демонстрация работы</h3>
В корне проекта
```python demonstration.py```
